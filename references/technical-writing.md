# 技术文本

明确要求严格模式，或误读代价较高的操作步骤、报错、工具说明及 agent 指令使用本规则。普通技术概念解释不必加载。

- 明确施事者、对象、条件、例外和顺序；施事者未知时不要编造。
- 严格操作指令一句一个动作。复杂步骤和分支分项，条件紧邻对应动作。短流程说明可连贯成段，避免把解释拆成碎片。
- 指令句 25 字、说明句 40 字仅作检查参考，不能为达标删掉条件、精度或独立信息。名词修饰和段落过长时优先理顺关系。
- 同一技术概念保持名称一致；“错误/异常”“检查/校验”等不同概念不可仅因词形近似而统一。
- 优先主语和动词，“进行＋动作名词”可简化；保留次数与进行中、已完成等状态。
- 必要限定放在对应主张附近；用真实原因解释取舍，不虚构被否定的方案。

机械检查的句长与词汇发现只作辅助，不能代替语义判断。
